### 获取手机号码归属地查询接口文档

#### 接口信息

- 接口状态 ： <Badge text="正常"/>
- 请求方式 ： `GET`
- 返回格式 ： `JSON`
- 扣除积分数 ： `1`

#### 请求地址

```shell
https://gateway.xwang.icu/api/PhoneInfo/18888888888
```

#### 请求参数

| 参数名   | 必选 | 类型     | 描述   |
|-------|----|--------|------|
| phone | 是  | string | 电话号码 |

#### 响应参数

| 参数名称          | 类型     | 描述       |
|---------------|--------|----------|
| code          | int    | 响应码      |
| phone         | string | 电话号码     |
| info.op       | string | 手机号归属运营商 |
| info.province | string | 省份       |
| info.city     | string | 城市       |
| info.zipcode  | string | 邮编       |
| info.areacode | string | 区号       |
| message       | string | 响应描述     |

### 代码示例

::: tip 注意 🔔️
没有开发者调用凭证无法调用接口哦！！！ [前往获取开发者凭证](https://api.xwang.icu/account/center)
:::

**注入Service**

```java
@Resource
private ApiService apiService;
```

- **示例一 ：推荐👍**
  **通过yml配置开发者调用凭证**

#### 代码示例

```java
@GetMapping("/PhoneInfo")
public ResultResponse getPhoneInfo(@RequestParam String phone) {
    PhoneParams phoneParams = new PhoneParams().setPhone(phone);
    return apiUtils.handleApiCall(() -> {
        PhoneRequest request = new PhoneRequest();
        request.setRequestParams(phoneParams);
        return apiService.getPhoneInfo(request);
    });
}
```

#### 响应示例

```json
{
  "phone": "查询的手机号",
  "info": {
    "op": "手机号归属运营商",
    "province": "省份",
    "city": "城市",
    "zipcode": "邮编",
    "areacode": "区号"
  },
  "message": "响应描述"
}
```
