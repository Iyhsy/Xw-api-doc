### 获取访客信息接口文档

#### 接口信息

- 接口状态 ： <Badge text="正常"/>
- 请求方式 ： `GET`
- 返回格式 ： `JSON`
- 扣除积分数 ： `1`

#### 请求地址

```shell
https://gateway.xwang.icu/api/visitor
```

#### 请求参数

| 参数名 | 必选 | 类型   | 描述                   |
| ------ | ---- | ------ | ---------------------- |
| 无     | 否   | string | 无需请求参数，直接调用 |

#### 响应参数

| 参数名称         | 类型   | 描述                 |
| ---------------- | ------ | -------------------- |
| code             | int    | 响应码               |
| data.time        | string | 当前时间             |
| data.week        | string | 当前星期             |
| data.ip          | string | 当前ip               |
| data.location    | string | 当前ip所在省市       |
| data.browser     | string | 当前浏览器           |
| data.browser_ver | string | 当前浏览器版本       |
| data.system      | string | 当前所使用系统       |
| data.low         | string | 当前所在地区最低温度 |
| data.high        | string | 当前所在地区最高温度 |
| data.tq          | string | 当前所在地区天气情况 |
| data.fl          | string | 当前所在地区风力     |
| data.tip         | string | 当前地区天气的评价   |
| data.fengxiang   | string | 当前地区天气的风向   |
| message          | string | 响应描述             |

### 代码示例

::: tip 注意 🔔️
没有开发者调用凭证无法调用接口哦！！！ [前往获取开发者凭证](https://api.xwang.icu/account/center)
:::

**注入Service**

```java
@Resource
private ApiService apiService;
```

- **示例一 ：推荐👍**
  **通过yml配置开发者调用凭证**
#### 代码示例

```java
@GetMapping("/visitorInfo/easyweb")
public BaseResponse<ResultResponse> getVisitorInfoEasyWeb(VisitorParams visitorParams) {
    ResultResponse response = apiUtils.handleApiCall(() -> {
        VisitorRequest request = new VisitorRequest();
        request.setRequestParams(visitorParams);
        return apiService.getVisitorInfo(request);
    });
    return ResultUtils.success(response);
}
```

#### 响应示例

```json
{
  "code": 0,
  "visitorInfo": "访客详细信息"
}
```
