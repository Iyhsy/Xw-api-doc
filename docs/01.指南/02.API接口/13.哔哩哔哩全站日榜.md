### 获取哔哩哔哩全站日榜接口文档

#### 接口信息

- 接口状态 ： <Badge text="正常"/>
- 请求方式 ： `GET`
- 返回格式 ： `JSON`
- 扣除积分数 ： `1`
#### 请求地址

```shell
https://gateway.xwang.icu/api/biliHot
```

#### 请求参数

| 参数名 | 必选 | 类型     | 描述          |
|-----|----|--------|-------------|
| 无   | 否  | string | 无需请求参数，直接调用 |

#### 响应参数

| 参数名称      | 类型     | 描述       |
|-----------|--------|----------|
| code      | int    | 响应码      |
| data.name | string | 	平台名称，这里指bilibili |
| data.subtitle| string | 		子标题，这里指全站日榜 |
| data.update_time | string | 	数据更新时间，格式为"YYYY-MM-DD HH:MM:SS |
| data.data.title | string | 	视频的标题 |
| data.data.hot | string | 	视频的热度，通常以“万”为单位 |
| data.data.url | string | 		视频的网页链接 |
| data.data.mobil_url | string | 	视频的移动端链接|
| data.data.index| int    | 		视频在全站日榜中的排名 |
| message   | string | 响应描述     |

### 代码示例

::: tip 注意 🔔️
没有开发者调用凭证无法调用接口哦！！！ [前往获取开发者凭证](https://api.xwang.icu/account/center)
:::

**注入Service**

```java
@Resource
private ApiService apiService;
```

- **示例一 ：推荐👍**
  **通过yml配置开发者调用凭证**

#### 代码示例

```java
@GetMapping("/biliHot")
public ResultResponse getBilibiliHot(BilibiliHotParams bilibiliHotParams) {
    return apiUtils.handleApiCall(() -> {
        BilibiliHotRequest request = new BilibiliHotRequest();
        request.setRequestParams(bilibiliHotParams);
        return apiService.getBiliHot(request);
    });
}
```
